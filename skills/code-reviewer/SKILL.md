# Legacy code-review reference adapter

Use `code-review` as the primary procedure. The three bundled analyzer scripts are unfinished scaffolds; they do not inspect code and must not be cited as evidence of a clean review. They fail explicitly until implemented.

Read `references/code_review_checklist.md`, `references/coding_standards.md`, and `references/common_antipatterns.md` only when those references help the review. Preserve useful content during consolidation. This entrypoint is a retirement candidate once callers and unique references migrate.
