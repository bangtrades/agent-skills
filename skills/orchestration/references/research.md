# Research

Read only the relevant section. The entrypoint controls execution budgets, context renewal and dispatch; this reference preserves detailed verification rules.

## Research-Fleet Discipline

- **Join citations to successful exact-source retrieval and inspect the relation itself.** A discovered URL or polished source summary is not evidence of an inspected original. Require ledger joins for every citation and claim, distinguish full text from query extracts, and separately check whether each typed relation describes implementation, prior work, analogy or a proposal. Passing schema and count gates cannot supply missing semantics.
- **Check source lifecycle as well as retrieval.** An accessible regulator page may be withdrawn guidance. Record publication/modification date separately from access, verify withdrawal or supersession for load-bearing rules, and preserve the still-valid statute separately from a revoked interpretation. A filename or failed fetch is not evidence of source content.
- **Treat retrieval as a capability matrix, not a binary installation check.** Probe each required surface (search, scrape, map/crawl, parse, async agent) against a tiny live target; record auth, quota, and response-shape failures; retry once; then fall back per operation to the best primary-source path. One working endpoint does not prove the rest, and one exhausted keyless route does not make the installed authenticated connector unusable. Record cost per surface alongside pass/fail — one `firecrawl_scrape` of an x.com post billed 30 credits while a Substack page embedding the same tweet cost 1; briefs carry a per-call cost ceiling with the cheap corroboration route named, and say up front when screenshots return as URLs an agent cannot see (2026-09-18). In the claude.ai chat surface `firecrawl_agent` may never receive its approval: probe the agent surface first with a trivial prompt, fall back to orchestrator-run search-per-slice, and say so in the acceptance report (2026-09-17).
- **Encode derived deliverable contracts in the artifact, not only in prose.** For agent/opportunity nodes, gate a coverage matrix across workflow, typed input, artifact output, real tool/API seam, failure risk, accountable human gate, and live metric. A fluent description with missing graph edges is incomplete because downstream builders load relations first.
- **Freeze the shared research contract before dispatch.** Hash acceptance thresholds, schema, reservations, and shared builders; make those paths explicit NO-GO for every slice; compare them on each return and before trusting any gate. If an agent changes the contract it is graded against, quarantine that wave, restore the frozen contract, and re-run every affected check on a quiet tree.
- **A reviewer must reproduce the deterministic gate, not summarize another agent's verdict.** Gate output from the current files and frozen configuration outranks prose that normalizes weaker thresholds or reports stale counts. Require exact command, exact configuration identity, and exact violations; a fresh model that merely agrees with an agent-reported PASS is not independent QA.
- **Every numeric claim lifted from a wide table carries its column header; the author's own disclaimer is a required field for any headline delta; the verification legend is defined in the report contract (2026-09-07 harness landscape).** Two slices cited one row of a vendor table and drew opposite conclusions because one slid a column; a 4/5 pitch was built on the inference the paper explicitly refuses; "verified" meant *found a source* in one file and *foundation-administered* in another. Brief researchers to quote `column → value` pairs, to search each primary source for its own caveats (`not`, `should not be interpreted`, `limitation`) and record the sentence verbatim before scoring, and to carry one glossary line per synthesis: who verified, against what. The gate makes same-source-different-value a mandatory check.
- **"Undrivable POST form" is a claim; read every Form D; the orchestrator-authored deliverable gets the same fresh gate (2026-09-11 Acres/Arcee).** Read a search form's field names and attempt one URL-constructed GET before filing the gap (the "undrivable" Arkansas SOS search was a plain GET that resolved two contradictions in one request). For any private US issuer with a CIK, open every `primary_doc.xml` — Item 5 carries the only Tier-A revenue band a private company emits, and record the consolidation scope with it. The final gate on the orchestrator's own report caught a P0 arithmetic error and an unlabelled author-built table; "verify, do not trust" briefs inverted the run's founding premise.
- **Paper-class claims are retrieved through the Firecrawl Research Index, and the ledger locator is the source id (2026-09-10).** A web snippet or scraped abstract page is not a paper citation. Briefs declare which tracks carry paper-class claims (methods, results, benchmark numbers, clinical evidence, prior art); those tracks use `firecrawl_research_search_papers` → `related_papers` (at least one expansion pass, pool size recorded) → `read_paper` for every quoted number, and cite `arxiv:` / `pmid:` / `pmcid:` / `doi:` with the operation class (`search` = abstract, `read` = full-text passage). The gate rejects a paper citation whose locator is a URL or whose quoted number lacks a `read` passage. This is not `search` + `categories: ["research"]`, which returns academic *web pages*. The capability-matrix probe includes the four `firecrawl_research_*` surfaces; keyless quota is shared across the fleet, so pass the authenticated key through MCP config before dispatch.
- **Hard thresholds, shared data fields and cross-slice facts are deterministic pre-web checks (2026-09-14).** A numeric screen band needs a stated pricing convention (multi-day average or ±tolerance) in the brief, and QA re-prices on the prior session — three band decisions inverted on a +7.9% sector day. A refuted shared data field is a class defect, not a slice finding: parallel slices have no channel, so the gate greps the whole wave for every card that consumed it. When slices touch one fact from different angles (a catalyst one slice ranks #1 that another found suspended), the gate diffs them *before* spending web calls.
- **Vault-writing waves obey the page contract and register their output (2026-09-14/17/19).** Frontmatter is a closed vocabulary, not a description: read `cortana-vault/scripts/vault-contract.json` before writing any page. `type:` is a declared type — never a `legacy_types` value on a new page; a page under `research/` is almost always `type: topic` — the first `tags:` element is exactly one declared emoji and no other emoji appears, and the six required keys (`title`, `type`, `created`, `updated`, `tags`, `status`) come first. If no declared value fits, use the closest declared value and say so in a `## Frontmatter note` line; proposing a new type or emoji is an operator decision for `_inbox/vault-dispositions/`, never a page's frontmatter. A template a slice authors is checked before any page is written from it. The wave's final gate is `scripts/vault-lint.py` scoped to the new folder, treating `legacy-*` warnings on pages authored in that run as failures. Before a research wave is declared complete, append a `## <Wave title> — <YYYY-MM-DD>` section to `research/research-hub.md` in the house form (wikilink row: folder index · brief · QA gate; what was produced in numbers; the standing quoting caveat), add the hub to the wave folder index's `related:`, and bump the hub's `updated:`.


## Eval-Wave Rules (blind identification / grading waves)

- **The blind spec is itself a gate artifact — version it.** A transcription ambiguity in the orchestrator's sanitized spec (a candle-count/clock contradiction) suppressed calls two agents demonstrably saw; patch + bump the version the moment a wave exposes the defect (don't let a known-bad gate keep firing), and record which agents ran on which version.
- **Instruct agents to record suppressed candidates in notes.** Signals seen-but-vetoed become recoverable adjudication evidence; without them a spec defect is indistinguishable from agent blindness.
- **Rotate or overlap day/case blocks across agents.** A 0/4 block score is confounded with block difficulty unless another agent sees the same block; rotation is the load-bearing control for any re-test.
- **QA must not certify recoveries it adjudicated past a threshold.** A verdict that crosses the gate only via its own adjudication is a re-test trigger, not a pass.
