- **2026-08-12 · WAI-48 approval queue (2 repos, 4 QA campaigns, live drill, 1 hotfix).** Three learnings. (1) *Law 4's deepest form:* the live drill caught `PgOpsClient.notify` missing — the fake implemented it, six call sites called it bare, two hid it behind `hasattr`, and crucially the PROTOCOL never declared it, so nothing structural could notice. Rule: for every protocol/fake/real triple, ship a conformance test in all four directions (protocol→real, fake→real, fake→protocol, protocol→fake) with signature comparison — fake→real is the load-bearing direction because it catches methods the protocol forgot. Treat any `hasattr(client, method)` guard on a seam as a finding in itself: it is how this class hides. (2) *Law 6 extends to BUILD backends:* an unpinned hatchling (installed fresh inside the Docker image build) shipped a stricter release and broke the production build with ZERO repo change (rejected `readme = "../README.md"`). Redeploys mask this for weeks — only real rebuilds exercise the floating dependency. Pin build-system requires, and treat "the build worked last week" as evidence about last week's toolchain, not this week's. (3) *Orchestrators eat their own trap food:* the data-modifying-CTE snapshot rule (already in this skill's history) bit the ORCHESTRATOR live — INSERT in a CTE + UPDATE of that row in one statement silently no-ops the UPDATE, and a 2s worker poll claimed the half-configured row before the repair round-trip landed. Drill-recipe rule: when arming a row a fast consumer can claim, insert it UNCLAIMABLE (a park status), configure it fully, then arm it with a separate plain UPDATE. Also reconfirmed ×3 in one evening: operator env-var paste traps (stale password; psql command tail glued into a DSN) — instructions must show the value with an explicit end marker ("ends at /postgres, nothing after"). Scoreboard: gate 1 caught 2 P1s (an unapproved gate could execute), the re-gate caught 2 P2s introduced BY the fix, the third gate went GO, and the live drill still found one more defect no gate could reach — every layer of the pipeline earned its keep on a single ticket.
