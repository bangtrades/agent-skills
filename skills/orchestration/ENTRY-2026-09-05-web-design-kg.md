## Additions (three, each cost something)

**(a) Law 1, fourth corollary — a scripted resolution of a semantic conflict is itself an
unverified premise.** I resolved 184 cross-predicate mirror pairs with a predicate-priority rule
(`part_of` > `measured_by` > `governed_by` > … > `references`) and let the wave proceed. Gate 2
sampled 30 and found the KEPT direction factually wrong in ~30% (`react-router-remix requires
shopify-hydrogen`; `webgl-hero-scene mitigates over-animated-enterprise-site-risk`). A full re-walk
by a fresh agent (13 swaps, 15 replacements, 2 drops) brought the sampled rate to ~10%. Rule: when a
deterministic rule adjudicates *meaning*, sample its output with a fresh reviewer before any wave
builds on it — the same way a QA repro's measurement method is part of the claim (Law 9).

**(b) A gate that counts satisfies itself; substance needs a second gate that reads.** The
multi-source excellence rule went through four compiler generations — ≥2 external source domains
→ ≥2 Recognition bullets → year + award-tier + `(domain)` per bullet, distinct domains, profile/
listing/directory excluded → `recognized_by` edge must match a bullet — and each generation was
green while bullets attached to campaign microsites, predecessor domains, native apps, a print
almanac, a competitor's blog, or an acquisition. Every rule was worth adding (each removed a class),
but the substance test still needed an Opus reader per gate. Corollary for research graphs: budget
one fresh-eyes substance pass per compiler generation, and expect the fix wave to introduce the next
class (fix-wave 2 resolved "directory presence" by bulk-adding one CSSDA bullet per firm — same
domain twice — and the floor backfills moved padding from `references` to other predicates).

**(c) When `SendMessage` is unavailable and edits are mechanical, a lead-run script plus a
per-track findings file beats N fix agents — but only for the mechanical part.** Same-predicate
mirrors, orphan `recognized_by` edges (30, matching the gate's count exactly), trash cleanup of
inbound references, and universe locking were all faster and safer as scripts with logs the agents
could review. The moment a decision needed a fact (direction, recognition validity, grounding
sentence), the script was the error source — see (a).
