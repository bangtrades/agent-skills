Typography

Aleo for headings. Lato for everything else.

Aleo Bold — Funding education, empowering students

Lato Regular — Body copy, paragraphs, navigation, fine print, table cells and captions all set in Lato. Warm, highly legible, and a clean counterpoint to Aleo's slab serifs.

Contrast rule. View #FFCD00 is a fill color, not a text color. Put Navy text on a View button; never set small yellow type on white.
