# HBEF PDF Instructions

PDFs for HBEF should be generated by one of two paths:

1. **Word → PDF export** (when content is text-heavy: letters, memos, annual reports, IC briefs). Use `references/docx-instructions.md` to build the Word doc, then export.
2. **HTML → PDF render** (when content is visual: one-pagers, infographics, dashboards, sponsor prospectuses). Use the `pdf` skill to render branded HTML.

This file covers the HTML→PDF path specifically. For Word→PDF, follow `docx-instructions.md` and use the resulting docx export. The final section covers **CMYK PDF/X export for commercial print**.

## Page setup (HTML→PDF)

- **Page size:** US Letter (8.5" × 11") portrait; 11" × 8.5" landscape for dashboards
- **Margins:** 0.5" top/bottom, 0.6" left/right (tighter than Word — PDFs have less reading distance)
- **Default body font stack:** `'Lato', 'Helvetica Neue', Helvetica, Arial, sans-serif`
- **Heading font stack:** `'Aleo', 'Roboto Slab', 'Zilla Slab', Rockwell, Georgia, serif` — always fall back to a **slab or serif**, never a sans
- **Both faces embed freely.** Aleo and Lato are SIL Open Font License 1.1. Unlike the retired proprietary display face, there is no licensing restriction on embedding them in a distributed PDF — always embed rather than relying on the reader's system fonts.

### Option B — Google Fonts link (online builds only)

Both families are free on Google Fonts. Put this in `<head>` **before** your stylesheet:

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Aleo:ital,wght@0,400;0,700;1,400;1,700&family=Lato:ital,wght@0,300;0,400;0,700;0,900;1,400;1,700&display=swap" rel="stylesheet">
```

Or as a CSS `@import`:

```css
@import url('https://fonts.googleapis.com/css2?family=Aleo:ital,wght@0,400;0,700;1,400;1,700&family=Lato:ital,wght@0,300;0,400;0,700;0,900;1,400;1,700&display=swap');
```

Prefer **Option A** for anything that must build reproducibly (CI, air-gapped, or a print vendor hand-off). Google Fonts serves WOFF2, which Playwright handles but some WeasyPrint builds do not.

## Running header & footer (HTML→PDF)

Use `@page` rules to define repeating margins. Note that CSS variables are **not** reliable inside `@page` margin boxes in most renderers — write the literal hex there.

```css

  size: letter;
  margin: 0.6in 0.6in 0.7in 0.6in;

  @top-left {
    content: "Q1 2026 Endowment Report";
    font-family: 'Lato', Helvetica, Arial, sans-serif;
    font-size: 8pt;
    font-weight: 700;
    color: #0C3B5D;
    text-transform: uppercase;
    letter-spacing: 0.5pt;
  }

  @top-right {
    content: "Confidential — Board Working";
    font-family: 'Lato', Helvetica, Arial, sans-serif;
    font-size: 8pt;
    font-style: italic;
    color: #98989A;
  }

  @bottom-left {
    content: "Hermosa Beach Education Foundation · hbef.org";
    font-family: 'Lato', Helvetica, Arial, sans-serif;
    font-size: 8pt;
    color: #98989A;
  }

  @bottom-right {
    content: "Page " counter(page);
    font-family: 'Lato', Helvetica, Arial, sans-serif;
    font-size: 8pt;

@page :first {
  /* Cover has no header/footer */

  @top-right { content: none; }

  @bottom-right { content: none; }
```

The brand footer pattern is: left = "Hermosa Beach Education Foundation · hbef.org", right = "Page N", both Lato 9pt Wet Sand, with a 1pt Teal `#186892` top border. When the renderer supports it, add the rule with `@bottom-center { border-top: 1pt solid #186892; }` or draw it as a `position: fixed` element in Playwright.

## Recommended toolchain

For HTML→PDF rendering, the `pdf` skill supports several backends. For HBEF deliverables, prefer (in order):

1. **Playwright + headless Chromium** — best CSS support including `@font-face`, `@page` margin boxes, flexbox, advanced layout
2. **WeasyPrint** — pure-Python, faithful CSS-Paged-Media support; no JS execution
3. **wkhtmltopdf** — fast, but older CSS engine; avoid unless others fail

When using Playwright, set `print_background=True` so colored bands (cover Navy, View footer, Sky dividers) render correctly.

### Playwright

```python
from playwright.sync_api import sync_playwright
from pathlib import Path

html = Path("build/report.html").resolve()

with sync_playwright() as p:
    browser = p.chromium.launch()
    page = browser.new_page()
    page.goto(html.as_uri())
    page.wait_for_load_state("networkidle")   # lets @font-face / Google Fonts settle
    page.evaluate("document.fonts.ready")     # guarantees Aleo + Lato are loaded before paint
    page.pdf(
        path="build/HBEF-Q1-2026-Endowment.pdf",
        format="Letter",
        print_background=True,                # REQUIRED — otherwise the Navy band drops out
        prefer_css_page_size=True,
        margin={"top": "0", "bottom": "0", "left": "0", "right": "0"},
    )
    browser.close()
```

### WeasyPrint

WeasyPrint resolves `@font-face` `src: url(...)` relative to the stylesheet, and embeds whatever it loads — no extra registration step needed. Pass a `base_url` so the relative `../fonts/` and `../logos/` paths resolve.

```python
from weasyprint import HTML, CSS
from weasyprint.text.fonts import FontConfiguration

font_config = FontConfiguration()

HTML(
    filename="build/report.html",
    base_url="build/",           # so ../fonts/Aleo-Bold.ttf and ../logos/*.png resolve
).write_pdf(
    "build/HBEF-Q1-2026-Endowment.pdf",
    stylesheets=[CSS(filename="assets/brand-palette.css", font_config=font_config)],
    font_config=font_config,
)
```

If WeasyPrint can't find the faces, register them explicitly through fontconfig by pointing at the bundled directory, or fall back to absolute `file:///Users/nolan/Projects/HBEF/HBEF BRANDING/...` URLs in the `@font-face` `src`. WeasyPrint reads TTF reliably; prefer the local TTFs over the Google Fonts WOFF2 link here.

### ReportLab (programmatic PDF, no HTML)

Register each TTF, then map the family so `<b>`, `<i>` and `<b><i>` resolve correctly.

```python
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.ttfonts import TTFont
from reportlab.lib.colors import HexColor
from reportlab.lib.styles import ParagraphStyle
from reportlab.lib.enums import TA_LEFT, TA_CENTER

FONT_DIR = "assets/fonts"

# ---- Aleo (headings, cover titles, display, pull quotes) ----
pdfmetrics.registerFont(TTFont("Aleo",   f"{FONT_DIR}/Aleo-Regular.ttf"))
pdfmetrics.registerFont(TTFont("Aleo-Bold", f"{FONT_DIR}/Aleo-Bold.ttf"))
pdfmetrics.registerFont(TTFont("Aleo-Italic", f"{FONT_DIR}/Aleo-Italic.ttf"))
pdfmetrics.registerFont(TTFont("Aleo-BoldItalic", f"{FONT_DIR}/Aleo-BoldItalic.ttf"))
pdfmetrics.registerFontFamily(
    "Aleo", normal="Aleo", bold="Aleo-Bold",
    italic="Aleo-Italic", boldItalic="Aleo-BoldItalic",
)

# ---- Lato (body, UI, tables, captions) ----
pdfmetrics.registerFont(TTFont("Lato",   f"{FONT_DIR}/Lato-Regular.ttf"))
```

## CMYK PDF/X export for commercial print

Everything above produces an **sRGB** PDF, which is correct for screen and office printing. Anything going to a commercial printer — laminated posters (36" × 24"), foam board (24" × 36"), 11" × 14" posters, street banners, step-and-repeats — must ship as **CMYK PDF/X** using the **CMYK `.eps` logos**.

### 1. Use the CMYK vector logos

RGB PNGs will separate badly. Pull the `.eps` files from the master library at `/Users/nolan/Projects/HBEF/HBEF BRANDING/LOGOS/`:

| Lockup | CMYK file (standard color) | CMYK file (dark backgrounds) |
|---|---|---|
| Primary Lockup | `HBEF-Primary_Lockup-CMYK.eps` | `HBEF-Primary_Lockup-Dark_Mode-CMYK.eps` |
| Primary Lockup + Tagline | `HBEF-Primary_Lockup_Tag-CMYK.eps` | `HBEF-Primary_Lockup_Tag-Dark_Mode-CMYK.eps` |
| Secondary Lockup | `HBEF-Secondary_Lockup-CMYK.eps` | `HBEF-Secondary_Lockup-Dark_Mode-CMYK.eps` |

Grayscale-only print uses `HBEF-Primary_Lockup-black.eps`. Solid-white knockouts use `HBEF-Primary_Lockup-white.eps` / `HBEF-Secondary_Lockup-white.eps` / `HBEF-Logomark-Dark_Mode.eps`. `.ai` sources sit alongside them for vendor hand-off.

Never convert an RGB PNG to CMYK yourself and never recolor an `.eps` — hand the vendor the file as released.

### 2. Convert the rendered PDF to PDF/X-4 CMYK

Ghostscript is the reliable path. Use a US coated profile (`USWebCoatedSWOP.icc` or `CoatedFOGRA39.icc`, whichever the vendor specifies).

```bash
gs -dPDFX -dBATCH -dNOPAUSE -dNOOUTERSAVE -dSAFER \
   -sDEVICE=pdfwrite \
   -dPDFSETTINGS=/prepress \
   -sColorConversionStrategy=CMYK \
   -sProcessColorModel=DeviceCMYK \
   -dOverrideICC=true \
   -sOutputICCProfile=/path/to/USWebCoatedSWOP.icc \
   -dEmbedAllFonts=true \
   -dSubsetFonts=true \
   -dCompatibilityLevel=1.4 \
   -sOutputFile=HBEF-Poster-CMYK-PDFX.pdf \
   PDFX_def.ps \
   HBEF-Poster.pdf
```

`PDFX_def.ps` is Ghostscript's PDF/X definition stub (ships in `lib/`); edit its `/OutputCondition` and `/OutputConditionIdentifier` to match the vendor's press profile before running.

For a `.eps`-driven layout, the cleaner route is to build the piece in Illustrator/InDesign (or hand the vendor the assets + specs) and export **PDF/X-4:2010**, CMYK, with fonts embedded. Aleo and Lato are OFL, so embedding is permitted with no rights clearance.

### 3. Print rules checklist

- **Bleed:** 0.125" on every trimmed edge
- **Safe margin:** live text ≥ 0.25" inside trim
- **Resolution:** 300 DPI at final size for anything held in the hand; 150 DPI at final size for anything read at distance (posters, banners, foam board)
- **Color space:** CMYK PDF/X for print, sRGB PNG/PDF for screen
- **Fonts:** embedded and subset — verify in Acrobat under File ▸ Properties ▸ Fonts that **Aleo** and **Lato** both appear as "Embedded Subset"
- **Logo clear space:** the height of the "HBEF" lettering on all four sides; minimum lockup width 1.25"
- **Rich black:** for large Navy areas ask the vendor for their preferred build rather than converting `#0C3B5D` yourself
- **Canva hand-off:** when the piece finishes in Canva, supply the exact hex codes, the Aleo/Lato role split, and which logo file to place — Canva can't read this stylesheet
