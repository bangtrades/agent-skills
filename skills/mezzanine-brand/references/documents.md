# Documents (.docx, .pdf, letters, briefs, candidate reports)

Read `docx` or `pdf` skill for mechanics.

## Page

Letter or A4, margins 1 in (top 1.25 in). Ground white for print documents; use paper `#EBE5DD` only for screen-first PDFs or a cover. Body ink `#141313`.

## Type (points)

Title 28–36 Austin Roman or Light, lh 1.0 · H1 20 Austin Medium · H2 14 Söhne Halbfett · body 10.5–11 Söhne Buch, lh 1.45 · caption 8.5 Söhne, muted `#6E6862` · eyebrow 8 Söhne caps +0.1 em red.
Both families are installed on the authoring Mac (`~/Library/Fonts/Austin/`, `/Library/Fonts/Söhne/`), so name them directly: font names `Austin`, `Söhne`. Embed fonts on PDF export. Use Georgia / Arial only when a file must open on a machine without them.

## Structure

Cover: wordmark PNG (ink) top-left at 2.4 in wide, title low-left in Austin, one red element (a 0.5 pt rule, the eyebrow, or a full red cover with ink type). Interior pages: 6 pt red rule under H1 is optional; prefer 0.5 pt `#DDD5C9` rules. Header: document title Söhne 8 caps. Footer: `MEZZANINE` Söhne 8 caps left, page number right, icon 0.35 in centred on last page only.

Tables: no fills, 0.5 pt rules, header row Söhne Halbfett caps 8 pt, numbers right-aligned, red only for one highlighted total.

Letterhead: wordmark ink 2.4 in top centre, address Söhne 8 caps bottom centre, icon 0.4 in above address (mirrors the guide's stationery). Address and phone must be confirmed by the client; the guide's `88 Wythe Ave` / `555` values are placeholders.

Callouts: paper `#EBE5DD` block with ink text, or ink block with paper text. Never a red text block longer than two lines.
